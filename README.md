# KAARVAN website

Static site for KAARVAN (Kaarvan Mobility). Plain HTML, one CSS file, two small JS files. No framework, no runtime dependencies.

```
index.html                 Home            https://kaarvan.in/
products/index.html        Products        https://kaarvan.in/products/
solutions/index.html       Solutions       https://kaarvan.in/solutions/
platform/index.html        Platform        https://kaarvan.in/platform/
about/index.html           About           https://kaarvan.in/about/
contact/index.html         Contact         https://kaarvan.in/contact/
404.html  sitemap.xml  robots.txt  .nojekyll
assets/css/site.css  assets/js/site.js  assets/js/contact.js  assets/fonts  assets/images
src/index.src.html         Source for copy and styles (build input, not a standalone page)
build.py                   Generates every page above from src/
```

## Preview locally
Best: open a terminal in this folder and run `python3 -m http.server 8000`, then visit http://localhost:8000. Double-clicking `index.html` also works for navigation (links are redirected to each folder's `index.html`), but browsers block the custom fonts on `file://`, so the text falls back to a system font. On a real web server or GitHub Pages everything loads normally.

## Editing
Edit `src/index.src.html` (copy, styles, markup), or the `PAGES` block at the top of `build.py` (page titles, descriptions, sitemap priority), then run `python3 build.py`. Commit the regenerated files. Python 3 only, no packages needed.

## Contact form (delivers to sales@kaarvan.in)
The form posts to [FormSubmit](https://formsubmit.co) (`data-endpoint` on `#kvContactForm`), which emails every inquiry to sales@kaarvan.in. No account or secret key is used.
1. After the site is live, submit the contact form once.
2. FormSubmit emails an activation link to sales@kaarvan.in. Click it once.
3. From then on inquiries arrive in that inbox.
Until step 2 is done the form does not claim success: it says the inquiry has not been delivered and offers a mailto link. Success is shown only when the service answers 2xx and reports `success`.
To use another service (Formspree, Web3Forms, your own endpoint), change `data-endpoint` in `src/index.src.html` and the payload in `assets/js/contact.js`, then rebuild.

## SEO
Real URLs per page, unique title and meta description, canonical, Open Graph and Twitter tags, JSON-LD (Organization, WebSite, WebPage, BreadcrumbList), `sitemap.xml`, `robots.txt`, `404.html` (noindex), semantic headings (one h1 per page), alt text on every image, `lang="en-IN"`, descriptive internal links, preloaded hero image and fonts.
After launch: add the site to Google Search Console and Bing Webmaster Tools and submit `https://kaarvan.in/sitemap.xml`; create a Google Business Profile for the Alwar address.
The domain `https://kaarvan.in` is set in `build.py` (`SITE`). Change it there and rebuild if the live address differs. Old links such as `/#products` forward to `/products/`.

## Deploying on GitHub Pages
Settings, Pages, "Deploy from a branch", branch `main`, folder `/ (root)`. The `CNAME` file (generated by `build.py`) keeps the custom domain `kaarvan.in`; keep it in the repo root when replacing files. All internal links are relative, so the site also works under `https://<user>.github.io/<repo>/` (canonical and social URLs still point at `SITE`).
